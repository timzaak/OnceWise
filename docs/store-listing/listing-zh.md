# Chrome Web Store 详细描述 — 中文(控制台添加 zh 语言 Listing 后粘贴到 Detailed description)

> "把验证过的网页操作固化为本地优先、按站点生效的可开关流程，由 AI 工具导入；启用后自动执行。"

---

OnceWise AI 把重复的网页操作变成自动执行的流程——全程本地，站点、步骤都由你说了算。

把一段网页例行操作描述给你的 AI 助手（任何能驱动 Chrome 的 agent，如装了 OnceWise skills 的 Claude Code、Cursor、ZCode）。AI 会在真实页面上试做一遍，提炼成一条受约束的流程流程，再经一条永不离开你设备的通道交付给本扩展。在侧边栏点一下启用——之后每次打开匹配的页面，OnceWise AI 都替你执行这些步骤。

为什么安全

• 本地优先：流程、设置与版本历史全部保存在浏览器本地存储。无账号、无分析、无遥测、无广告、无追踪。
• 按站点生效：流程只在其编写时指定的站点上运行；内容脚本只注册到真正携带流程的站点，某站点最后一条流程删除后即解除注册。
• 天生受约束：流程是受限流程（填写、点击、读取、等待、断言、循环）并带时间预算——不是任意脚本。敏感值在侧边栏一律脱敏显示。
• 你始终掌控：每条流程都有开关、可回滚的最近 10 版历史和删除按钮；同一业务实例在同一会话内绝不重复提交。
• AI 交接通道是本机原生消息宿主（需单独安装，要求 Node 22+），它承载的一切都留在你的设备上。

可选的自托管同步

运行开源的 oncewise-ai-sync 服务器（或使用你信任的实例），把选定流程以带版本的脚本形式通过空间码分享给同事与设备。完全可选——没有它扩展照常工作。

如何开始

1. 安装本扩展。
2. 在你的 AI 工具中安装下方仓库提供的 OnceWise skills，它会引导 agent 构建、校验并交付流程。
3. 安装一次本机宿主：`node skills/oncewise-message/install.mjs`（要求 Node 22 及以上）。
4. 让 AI 在当前页面录一条流程，然后在侧边栏检查并点击启用。

流程也可以来自同步空间：在「同步」页签填入你的服务器地址，拉取共享脚本即可。
