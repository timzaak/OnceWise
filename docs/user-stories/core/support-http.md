## 用户故事

### 故事 1：流程声明数据上报步骤并在摘要中显著可见 [US-HTP-001]

**优先级**: P1

**【用户故事】**
**作为**：AI 工具用户
**我希望**：AI 在流程文件里为我声明"把本次采集到的数据上报到我的服务器"的步骤（目的地网址、请求方式、上报哪些数据、凭据引用名都写在流程文件里），保存前的摘要把这些外发内容显著展示出来
**从而**：我能在启用前清楚看到数据将被发往哪里、发了什么，再决定是否启用

**【验收标准】**

**场景 1：保存含上报步骤的流程，摘要显著展示外发信息**
```gherkin
Given AI 经本机通道交付一个包含上报步骤的流程（https 目的地、GET/POST、数据引用与凭据引用名）
When 校验通过进入保存摘要
Then 摘要以外发级别标注展示每个上报步骤的目的地网址、上报数据来源与凭据引用名，与提交类动作同级显著
```

**场景 2：非 https 目的地整体拒绝**
```gherkin
Given AI 交付的流程含一个 http 明文上报目的地
When 扩展执行交付校验
Then 该流程被整体拒绝并说明原因（上报目的地必须为 https），不保存任何部分
```

**场景 3：保存后默认未启用**
```gherkin
Given 一个含上报步骤的流程经确认保存成功
When 保存完成
Then 该流程处于未启用状态，启用只能由用户本人操作
```

### 故事 2：运行时上报并按服务端结果继续 [US-HTP-002]

**优先级**: P1

**【用户故事】**
**作为**：AI 工具用户
**我希望**：流程运行到上报步骤时自动把采集数据发送到我的服务器，成功（成功状态区间）就继续后续步骤，可选地把服务端返回内容捕获下来供流程后续判断使用
**从而**：例行的"采集→上报→按服务端结果处理"闭环无需人工搬运数据

**【验收标准】**

**场景 1：上报成功并继续**
```gherkin
Given 一个已启用流程，运行至上报步骤，目标服务器可达且返回成功状态
When 上报步骤执行完成
Then 采集数据被发送到流程声明的目的地，运行继续执行后续步骤
```

**场景 2：捕获响应供后续判断**
```gherkin
Given 流程的上报步骤声明了响应捕获，服务器返回内容未超过大小上限
When 上报成功
Then 后续步骤可对捕获的响应内容做条件判断或引用，捕获内容只作为数据处理
```

**场景 3：上报失败保守中止**
```gherkin
Given 流程运行至上报步骤
When 服务器返回失败状态、网络不可达、等待超时，或响应超过大小上限
Then 该次运行保守中止（失败），失败提示含节点、环节与简短原因，不自动重试，已完成的页面操作不回滚
```

### 故事 3：本机管理上报凭据 [US-HTP-003]

**优先级**: P1

**【用户故事】**
**作为**：AI 工具用户
**我希望**：在扩展内为本机录入具名凭据（只存本机、不同步），流程文件按引用名使用，运行时凭据缺失或无效能明确提示
**从而**：上报服务器的认证凭据不随流程共享泄漏给空间成员，也能在缺凭据时知道该补哪个

**【验收标准】**

**场景 1：录入本机凭据并被流程引用**
```gherkin
Given 用户在扩展内录入一个具名凭据（如"我的上报服务器"）
When 一个引用该凭据名的已启用流程运行至上报步骤
Then 请求携带该凭据完成上报，凭据值不出现在摘要、失败提示或同步内容中
```

**场景 2：凭据缺失保守中止**
```gherkin
Given 一个引用凭据名"我的上报服务器"的已启用流程，本机未录入该凭据
When 流程运行至上报步骤
Then 该次运行保守中止并提示缺少凭据"我的上报服务器"，不静默跳过上报，不产生外发
```

**场景 3：凭据不随流程同步**
```gherkin
Given 设备 A 把含凭据引用名的流程保存进同步空间，且本机已录入凭据值
When 设备 B 从空间拉取该流程
Then 设备 B 只获得流程定义与凭据引用名，不获得凭据值；设备 B 需自行录入本机凭据后上报步骤才可运行
```

### 故事 4：拉取/共享流程中的上报步骤可见性 [US-HTP-004]

**优先级**: P1

**【用户故事】**
**作为**：AI 工具用户（空间参与者）
**我希望**：从同步空间拉取的含上报步骤的流程，同样在保存摘要与流程清单中显著标示外发目的地
**从而**：我不会在不知情的情况下启用一个会把我的页面数据发往他人服务器地址的流程

**【验收标准】**

**场景 1：拉取端摘要同样展示外发信息**
```gherkin
Given 设备 B 从空间拉取一个含上报步骤的脚本
When 保存摘要展示
Then 外发目的地、上报数据来源与凭据引用名按与本地交付相同的外发级别标注展示，流程清单对该流程显示外发标注
```

**场景 2：启用决定仅归本机用户**
```gherkin
Given 设备 B 拉取保存的含上报步骤流程处于未启用状态
When 用户 B 未主动启用
Then 该流程在设备 B 上零外发、零页面动作
```
