> 角色：**AI 工具用户**（US-FS-001～003）与**空间参与者**（US-FS-004，共享场景），定义见 [`docs/user-stories/_roles.md`](../_roles.md)。

## 用户故事

### 故事 1：填写流程声明的输入项 [US-FS-001]

**优先级**：P1

**【用户故事】**

**作为**：AI 工具用户（详见 `docs/user-stories/_roles.md`）  
**我希望**：在流程详情中填写 AI 为该流程定义的输入项，并保存供后续自动触发使用  
**从而**：流程所需的业务数据由我提前提供，无须在每次触发时重复输入

**【验收标准】**

**场景 1：填写并保存多种输入项**

```gherkin
Given AI 产出的流程声明了必填文本、数字和日期，以及选填单选、复选、时间和多选输入项
When 我在流程详情填写或选择有效值并保存
Then 流程详情显示已保存的输入状态；下次自动触发可使用这些值
```

**场景 2：无法保存无效值**

```gherkin
Given 流程声明了数字输入项和单选候选项
When 我输入非数字内容，或流程原有选项变化使已选值不再有效，并尝试保存
Then 流程详情指出具体错误项；无效值不会成为下一次自动执行使用的数据
```

### 故事 2：同一次流程复用启动时的输入值 [US-FS-002]

**优先级**：P1

**【用户故事】**

**作为**：AI 工具用户（详见 `docs/user-stories/_roles.md`）  
**我希望**：流程启动后，后续不同步骤都能引用我提前保存的输入值  
**从而**：同一业务数据在整次自动化流程中保持一致

**【验收标准】**

**场景 1：两个步骤复用同一值**

```gherkin
Given 我已在流程详情保存一个有效输入值，且流程的两个不同步骤都会使用它
When 流程按既有触发条件自动启动并完成流程
Then 两个步骤都使用同一个已保存值，页面上的相应结果均与该值一致
```

**场景 2：运行中修改只影响下一次**

```gherkin
Given 流程已经使用保存值 A 开始执行，后续步骤尚未完成
When 我在流程详情把该输入改为 B 并保存
Then 当前流程的后续步骤仍使用 A；下一次自动触发的流程使用 B
```

### 故事 3：缺少必填数据时安全跳过 [US-FS-003]

**优先级**：P1

**【用户故事】**

**作为**：AI 工具用户（详见 `docs/user-stories/_roles.md`）  
**我希望**：流程缺少必填输入或输入无效时不开始操作，并能看到需要修正的项目  
**从而**：避免自动化带着不完整的数据修改网页

**【验收标准】**

**场景 1：缺少必填项**

```gherkin
Given 已启用流程声明了必填输入项，但我尚未填写
When 流程的自动触发条件满足
Then 本次执行被跳过，页面没有该流程产生的自动动作；流程详情列出缺失项
```

**场景 2：选填项为空**

```gherkin
Given 流程的必填项均有效，选填项未填写
When 流程的自动触发条件满足
Then 流程可以开始执行；选填项为空不会被当成缺少必填项
```

### 故事 4：共享流程时保留个人输入边界 [US-FS-004]

**优先级**：P1

**【用户故事】**

**作为**：空间参与者（详见 `docs/user-stories/_roles.md`）  
**我希望**：共享流程定义时只共享输入项的定义，不共享我在本机填写的值  
**从而**：其他参与者能复用同一流程，并自行提供各自的数据

**【验收标准】**

**场景 1：上传和拉取流程**

```gherkin
Given 我已在本机为流程填写并保存输入值
When 我把该流程保存到同步空间，另一位参与者拉取它
Then 对方能看到流程定义的输入项，但看不到我的填写值；对方在本机填写自己的值后才能用于自动执行
```

**场景 2：缺少本机必填值的拉取流程**

```gherkin
Given 我刚拉取一条声明了必填输入项的流程，且本机没有对应保存值
When 我启用流程并满足自动触发条件
Then 本次执行被跳过，流程详情列出缺失项；我填写并保存后，后续触发可执行
```
