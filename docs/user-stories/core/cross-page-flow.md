## 用户故事

### 故事 1：一条流程完成同一站点的多个页面 [US-CPF-001]

**优先级**: P0

**【用户故事】**
**作为**：AI 工具用户（详见 [docs/user-stories/_roles.md](../_roles.md)）
**我希望**：把同一业务在同一个站点多个页面上的连续操作（如向导式表单：填写页→确认页→结果页）放进一条流程，流程声明每一页的特征与"跳到下一页后继续"，前一步读取的数据在后一页仍可使用
**从而**：跨页业务不再被拆成多条流程手工衔接，整段操作启用后自动完成，同一张单据最终只提交一次

**【验收标准】**

**场景 1：多页流程顺序完成**
```gherkin
Given 一条跨页流程已启用，它声明了入口页与后续各页，每页各有自己的步骤
When 我打开入口页面完成触发（或触发条件自动满足）
Then 流程在每一页按序执行该页步骤；每次跳转到声明的下一页后运行继续，直到最后一页完成；同一张单据的最终提交只发生一次
```

**场景 2：下一页在新标签页打开时继续**
```gherkin
Given 站点把流程声明的下一页在新标签页打开（如确认按钮以新页方式打开结果页）
When 跳转发生
Then 流程在新标签页的声明页面上继续执行；原标签页不再产生自动动作
```

**场景 3：下一页未按时到达即失败并可见**
```gherkin
Given 流程声明了跳转后等待下一页的截止时间
When 跳转后声明页面在截止时间内没有出现（如点击后停留在原页或去了其他页面）
Then 本次运行失败停止，不重试跳转；流程清单显示失败发生在哪一页哪一步；已完成页面上的操作保留，由我接手处理
```

**场景 4：意外中断保守取消且不重复提交**
```gherkin
Given 一条跨页流程正在执行（或刚跳转、等待在下一页继续）
When 我手动刷新运行中的页面、关闭运行所在标签页或重启浏览器
Then 本次运行取消，不自动从断点恢复；同一张单据不会因中断后的再次进入而被重复提交
```

**场景 5：同一业务实例跨页只执行一次**
```gherkin
Given 一条跨页流程已对某张单据执行过提交类动作
When 我刷新入口页或重复进入流程声明的任一页面
Then 该单据不被再次处理（本会话内已占用）；流程显示跳过及原因，不产生任何自动动作
```

**场景 6：中途失败后数据与已完成操作留在页面上**
```gherkin
Given 流程已在第一页填写并提交，运行继续到后续页面
When 后续某页的某一步失败（元素缺失、校验不通过或等待超时）
Then 失败信息指出页与步骤；已发生在各页上的操作不回滚，剩余步骤不执行
```
