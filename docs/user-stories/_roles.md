# 用户故事角色定义

> 本文件是用户故事的统一角色参考。用户故事中的角色必须引用此处定义，不得在故事内重复定义；新增或修改角色时先更新本文件，再在用户故事中引用。

## AI 工具用户

- **定义**：已在日常使用 Codex、Claude Code 等 AI 编程工具，能在自有工具协助下描述、探索并验证网页局部操作，希望把验证过的操作固化为可开关流程重复使用的人。
- **特征**：不写站点专用脚本，不依赖开发者维护插件；熟悉自有 AI 工具的 Skill 与 MCP 配置；对启用流程后的自动执行结果（含保存/提交/确认类动作）自行承担风险边界。
- **诉求**：不依赖开发者，把一次验证成功的网页操作固化为可开关流程并可靠复用，在流程出错时能自己定位与维护。

## 空间参与者（创建者 / 加入者）

- **定义**：持有某同步空间访问密钥的 AI 工具用户。"创建者"在本机生成空间 ID 与密钥并注册到自建服务器；"加入者"凭创建者分享的空间码（`空间ID#密钥`）加入。两者是同一角色的两种进入方式，权限完全对等。
- **特征**：服务端没有账号体系，"持有密钥"即全部访问依据；空间清单只保存在各端本机；本机可能已有启用中的流程，自主决定本机使用哪个脚本版本，本地执行版本不被他人更新自动改变。
- **诉求**：免注册地把团队验证过的脚本共享起来，直接使用，不被他人更新打扰，出问题时能回退；空间不再使用时可本机忘记或服务端删除。
- **边界**：不代替他人启用流程；密钥即访问权——分享对象即协作范围（互信小圈子定位）。
