Oncewise AI Browser Extension — Privacy Policy

Effective date: 2026-09-28

Overview

Oncewise AI is a self-service browser automation extension. It turns web page operations you specify into automation rules ("constrained workflows") and runs them on the target pages you choose. The extension is local-first: your data is processed in your browser, and the extension developer does not collect, receive, or sell any of your data.

What the extension stores on your device

  • Automation rules/workflows and their settings, kept in the extension's local storage (chrome.storage).
  • Import history entries for rule files you import (local files only).
  • Short-lived session data used to prevent duplicate submissions on the same business instance (business identifiers only, cleared when the browser session ends).

Data read from web pages during a rule run is processed in memory to execute that workflow; it is not persisted by the extension beyond the rule definitions above.

Data transmission

The extension makes network requests to exactly one kind of destination, and only when you configure it:

  • A sync server you configure. If you set up synchronization, the extension sends your rules/scripts and related configuration to the oncewise-ai-sync server URL you enter, authenticated with the space key you provide. That server is operated by you or whoever you trust with the URL. The extension developer operates no server in this loop and never sees your data.

There is no analytics, telemetry, advertising, or tracking of any kind, and the extension contains no remotely hosted code.

Permissions and why they are needed

  • storage — persist your rules and settings locally.
  • scripting and host permissions for all http/https sites — every rule targets a site that you choose. Because targets cannot be known at install time, the permission must be requested up front; in practice, content scripts are registered only for the origins that actually carry your rules, and are removed when the last rule for a site is deleted.

Retention and deletion

  • Uninstalling the extension deletes all locally stored rules and settings.
  • Data previously synced to a sync server is governed by the operator of that server; remove it with that server's own means (or stop using it).

Changes

If this policy changes, the updated version will be published at the same URL with a new effective date.

中文

Oncewise AI 浏览器扩展 — 隐私政策

生效日期：2026-09-28

概述

Oncewise AI 是一个自助浏览器自动化扩展。它把你指定的网页操作固化为自动化规则（受约束工作流），并只在你选择的目标页面上运行。扩展以本地优先方式工作：数据在你的浏览器内处理，扩展开发者不收集、不接收、不出售你的任何数据。

扩展在设备上存储的内容

  • 自动化规则/工作流及其设置，保存在扩展本地存储（chrome.storage）中。
  • 你导入的规则文件（仅本地文件）的导入记录。
  • 用于防止同一业务实例重复提交的短期会话数据（仅业务标识，浏览器会话结束即清除）。

规则运行期间从网页读取的数据仅在内存中用于执行该工作流；除上述规则定义外，扩展不会将其持久化。

数据传输

扩展只向一类目的地发起网络请求，且仅在你主动配置时发生：

  • 你配置的同步服务器。 若你启用同步，扩展会把你的规则/脚本及相关配置发送到你填写的 oncewise-ai-sync 服务器地址，并使用你提供的空间密钥认证。该服务器由你或你信任的地址运营者管理；扩展开发者在链路中不运营任何服务器，也永远看不到你的数据。

扩展不含任何分析、遥测、广告或追踪代码，也不含远程托管代码。

权限及必要性

  • storage — 在本地保存你的规则和设置。
  • scripting 与全站 http/https 主机权限 — 每条规则的目标站点由你指定，安装时无法预知目标，因此只能预置申请；实际使用中，内容脚本只注册到真正携带规则的站点，某站点最后一条规则被删除后即解除注册。

保留与删除

  • 卸载扩展即删除本地存储的全部规则和设置。
  • 已同步到同步服务器的数据由该服务器的运营者管理；请通过该服务器自身的手段删除，或停止使用。

政策变更

政策如有变更，将在同一地址发布更新版本并更新生效日期。
