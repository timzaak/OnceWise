SSBA 受控测试页（入口，非命中负样本）

本目录是"自助浏览器局部自动化"扩展的受控验证场所：全部本地静态文件，零外部依赖、零网络请求。

  • form-page.html —— 命中页 A：仿 antd 下拉、原生下拉、文本、复选、提交按钮「保存」、成功横幅（preState 目标）。
  • other-page.html —— 隔离样本：同站同字段 id、不同 URL 路径；命中特征为 /form-page.html 的流程在此必须零动作。
  • app-spa.html —— SPA 行为模拟：hash 路由 + 同 document 视图重挂（防重复护栏验证）。

启动方式与站点授权说明见 README.md（例如 python -m http.server 8123 后经 http://localhost:8123/ 访问）。
